# RouterFlow: site, downloads e verificação de licença

Este repositório público hospeda:

- o site do RouterFlow (GitHub Pages): `index.html`, `site.css`, `img/`;
- `licencas/estado.json`: renovações e revogações de licença, assinado pelo emissor;
- `versao.json`: última versão publicada, assinado pelo emissor;
- os instaladores, em Releases.

O programa confere a assinatura com a chave pública embarcada. Arquivos editados à mão são ignorados.
